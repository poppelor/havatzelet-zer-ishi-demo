# חיבור הטופס לגיליון

פריסה חד-פעמית בחשבון גוגל של אור, ואז הטופס בטלפון ישמור שורות בגיליון בלי התחברות.

1. לפתוח את הגיליון.
2. תוספים > Apps Script, להדביק את `Code.gs`, לשמור.
3. פריסה > פריסה חדשה > אפליקציית אינטרנט.
   - הרצה בתור: אני
   - מי יש לו גישה: כל אחד
4. להעתיק את כתובת האפליקציה אל `ENDPOINT` ב-`index.html`, ולפרסם מחדש את הדף.
