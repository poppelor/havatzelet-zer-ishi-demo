# טופס דמו: זר בהתאמה אישית — משתלת חבצלת

טופס טלפון לחישוב מחיר של זר בהתאמה אישית, עם מחירים לדוגמה בלבד.

- טופס: לאחר פרסום GitHub Pages, הכתובת היא `https://poppelor.github.io/havatzelet-zer-ishi-demo/`
- גיליון הדיווחים בגוגל דרייב של אור: https://docs.google.com/spreadsheets/d/1l_JPnqbnNw5dmrVyC6e7q0_EUOnVGSuPij3Ub1Qnoes/edit

המחירים בטופס הם מחירים לדוגמה מפריטי ניסיון בקופה, לא מחירי ספק אמיתיים.

החישוב: סכום הענפים, ואז עיגול כלפי מעלה לכפולה של 5 ש"ח.
דוגמה: 5 ורדים + 3 ליזיאנטוס + 4 ירק = 144, ואחרי עיגול 145.

השמירה האוטומטית לגיליון דורשת פריסת Apps Script חד-פעמית (ראה `apps-script/`).
