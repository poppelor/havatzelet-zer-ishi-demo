## פריסת הסקריפט מחדש (חובה לטפסים החדשים)

הטופס הישן (זר בהתאמה אישית) ממשיך לעבוד בלי פריסה חדשה.
הטפסים החדשים נשמרים ללשוניות נפרדות רק אחרי עדכון הפריסה הקיימת, בלי לשנות את כתובת ה-/exec:

1. לפתוח את הגיליון.
2. תוספים > Apps Script.
3. להחליף את `Code.gs` בתוכן שב-`apps-script/Code.gs`, ולשמור.
4. פריסה > ניהול פריסות > עיפרון על הפריסה הקיימת.
5. ב"גרסה" לבחור "גרסה חדשה", ולאשר פריסה.
   להשאיר: הרצה בתור — אני; מי יש לו גישה — כל אחד.
   לא ליצור פריסה חדשה.
