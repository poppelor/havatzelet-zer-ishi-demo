# טופס דמו: זר בהתאמה אישית — משתלת חבצלת

טופס טלפון לחישוב מחיר של זר בהתאמה אישית, עם מחירים לדוגמה בלבד, כולל הנחה.

- טופס: https://poppelor.github.io/havatzelet-zer-ishi-demo/
- גיליון: https://docs.google.com/spreadsheets/d/1l_JPnqbnNw5dmrVyC6e7q0_EUOnVGSuPij3Ub1Qnoes/edit

המחירים בטופס הם מחירים לדוגמה מפריטי ניסיון בקופה, לא מחירי ספק אמיתיים.

החישוב: סכום הענפים, פחות הנחה אם יש, ואז עיגול כלפי מעלה לכפולה של 5 ש"ח.
דוגמה בלי הנחה: 5 ורדים + 3 ליזיאנטוס + 4 ירק = 144, ואחרי עיגול 145.
דוגמה עם הנחה 20%: 144 − 28.8 = 115.2, ואחרי עיגול 120.

השמירה לגיליון עוברת דרך Apps Script שכבר פרוס. אחוז ההנחה נשמר בעמודת G (השדה wrapping בסקריפט) וסיבת ההנחה בעמודת L (השדה photo). אין צורך בפריסה חדשה.
